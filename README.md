# Leon Hou's Personal Homepage

Hi, I'm Leon Hou (侯亮). This is my long-term personal homepage for research, numerical experiments, building, learning, and thinking.

🔗 **[leonyun107.github.io](https://leonyun107.github.io/)**

## Site Direction

- **Research & Science** — atmospheric blocking, climate dynamics, environmental science, numerical modeling
- **Technology & Building** — data tools, AI agents, research automation, personal projects
- **Life & Thinking** — reading, learning systems, personal growth, and reflections

The site is not a one-shot resume. New pages are added only when there is real work, evidence, or writing worth sharing.

## Structure

```text
.
├── index.html                 # Homepage
├── about.html                 # About Leon
├── projects/                  # Work index and project pages
├── assets/                    # Public, optimized site assets
├── styles.css                 # Shared visual system and responsive layout
├── script.js                  # Year display and accessible mobile menu
├── robots.txt
└── sitemap.xml
```

No framework, package installation, build step, or database is required. The site is plain HTML, CSS, and JavaScript and is deployed from the repository root with GitHub Pages.

## Local Preview

For correct relative links and assets, serve the directory with any simple static server. Opening individual HTML files directly also works for most checks.

## Content Boundaries

- Research training and course projects are labelled as such.
- Interests are not presented as mature professional abilities.
- No private contact information, raw research data, third-party personal information, application materials, or credentials belong in this repository.
- Source code for the featured numerical projects is not published on the website at this stage.

## Deployment

GitHub Pages serves the `main` branch from `/ (root)`. Feature work should be reviewed locally before it is merged and pushed.
