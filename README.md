## Project Structure

Three core files and nothing more:

| File | Purpose |
|------|---------|
| `index.html` | Page content and structure |
| `styles.css` | Visual styling and responsive layout |
| `script.js` | Year display and mobile menu |

No frameworks, no build tools, no database. Open `index.html` directly in a browser, or let GitHub Pages serve it. Simple enough to maintain for years.

## Local Preview

- **Quickest**: Double-click `index.html`.
- **With live reload**: Install the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) VS Code extension, then right-click `index.html` → **Open with Live Server**.

## Deployment

Published via [GitHub Pages](https://pages.github.com/) from the `main` branch, root directory. To set up from scratch:

1. Go to repo **Settings** → **Pages**
2. Under **Build and deployment**, select **Deploy from a branch**
3. Choose branch `main`, directory `/ (root)`
4. Save — the first build may take a few minutes
